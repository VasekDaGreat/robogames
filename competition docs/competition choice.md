# Selection process

## finding competitions

A lot of searching with a lot of results for HS comps but only a few for uni students.

In the end found following candidates:
- Matfyz robot day
- robogames (in Zlín)
- robotour

Robotour seemed to ambitious and matfyz robot day doesn't have any info for the following year so we decided to go for robogames.

Out of the Robogames categories we found that the one that most matched the nail073 subject was "Robot uklízeč"
